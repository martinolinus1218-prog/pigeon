# 赛鸽飞行模拟游戏

一款基于HTML5、CSS3和JavaScript开发的网页小游戏，玩家通过控制赛鸽躲避管道障碍，尽可能飞得更远以获取更高分数。

## 游戏特点

- 简约大气的视觉风格
- 流畅的游戏体验
- 响应式设计，适配不同设备
- 多种操作方式
- 计分系统

## 游戏操作

- 使用鼠标点击或键盘空格键控制赛鸽向上飞行
- 松开后赛鸽会受重力影响下落
- 躲避从右侧出现的管道障碍
- 每穿过一组管道得1分
- 碰到管道或边界游戏结束

## 如何运行

1. 下载项目文件
2. 直接在浏览器中打开`index.html`文件
3. 点击"开始游戏"按钮开始游戏

## 项目结构

- `index.html`：游戏页面结构
- `style.css`：游戏样式和视觉效果
- `script.js`：游戏逻辑和交互
